# 星の節目シングルチャート 2000〜2050年版

公開前の確認候補。完成版やライセンス適合済みの配布物として扱わない。

展開先で bash build.sh を実行する。必要環境は C コンパイラ、Python 3、Node.js、GNU sha256sum。候補を開くファイルは single2000/index.html。ビルドは保存された共通エンジンv1.0のコードと同梱Swiss Ephemeris Cソース・天文暦から錨となる3時間刻みのサンプルを生成し、新月・満月・入座・食分類の表を作る。v18の使用済みイベント表も、旧共通エンジンの2000〜2050年バイナリもビルドに不要。検査対象の同梱版はシングルチャート専用。

以前の候補との比較では12,025件の日時表示、サイン、進行方向、逆行フラグと食230件の対応・分類が一致。黄経の最大差は月の0.76014秒角。旧共通エンジン入力と比較して地球姿勢のバイナリは同一、黄経・速度バイナリと順逆の切替時刻表は異なる。今回の原本とする入力は同梱ソースから作った新しい表。年代範囲と三種イベント、地点変更、チャートと模式図のPNG保存ハンドラを模擬DOMで検査。実ブラウザとiPad Safariでの表示・実ファイル出力は未検査。

Swiss Ephemerisの出所は共通エンジンv1.0が記録する upstream commit 26c9897279736b76e81f0b0039d05283a9ba59dc5。原本ZIPは Library ID libfile_ad80fc8d20fc8191b06022d35c6c80de。Swissのライセンス案内とAGPL本文は common-engine-inspection/common-engine/research/swiss に収録。HTML内にGeoNLPのCC BY 4.0とDejaVu由来アウトラインの表示を保つ。アプリ自身をどの条件で公開するかと、ブラウザ配信から対応ソースへの案内は本番反映前に確定する。

## PNG保存の修正

iPadでチャート・模式図とも保存できない報告を受け、CanvasのPNGをクリック処理内で生成し、同期的にダウンロードを開始する。画像と再試行リンクも表示し、iPadでは画像を長押しできる。計算データはこの修正の対象外。修正版のiPad Safari実機結果は未確認。

更新版はファイル共有に対応したiPadでPNGファイルをOS標準共有シートへ直接渡す。実機未検査。
